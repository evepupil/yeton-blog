Edge 地址栏全选网址后，按 `Ctrl+C` 或右键复制，粘贴出来都是空白；网页文字和部分选中的网址却能正常复制。本次打开设置中的**“更改 URL 复制和粘贴格式”**开关后，完整网址复制恢复正常。

## 解决办法

1. 打开 Edge **设置**，在设置页的搜索框中输入 **复制**。
2. 找到 **外观 → 浏览器行为和功能 → URL 格式设置** 下的 **更改 URL 复制和粘贴格式**。
3. 将右侧开关打开，调整到下图红框中的蓝色状态。

![Edge 设置中搜索“复制”，红框标出了“更改 URL 复制和粘贴格式”，右侧开关已开启](/images/posts/edge-address-bar-copy-empty/edge-url-copy-paste-setting.png)

图中展示的是本次恢复正常后的设置。需要调整的是红框中的 URL 格式开关。

也可以把下面的地址输入 Edge 地址栏并回车，直接进入“浏览器行为和功能”页面：

```text
edge://settings/appearance/browserBehavior
```

微软帮助文档还介绍了“链接”和“纯文本”两种格式。本文记录的有效操作是**打开截图中的开关**，没有额外切换到“纯文本”的验证记录；如果你的设置界面不同，以当前界面和微软说明为准。

## 问题详情

故障发生在复制当前网页的完整网址时。地址栏已经全选，执行复制后，到其他地方粘贴，预期得到网址，实际得到空白。快捷键和右键菜单都能触发同样的问题。

当时几种操作的结果如下：

| 操作                             | 结果     |
| -------------------------------- | -------- |
| 在网页正文中选中文字再复制       | 正常     |
| 在地址栏只选中网址的一部分再复制 | 正常     |
| 在地址栏全选网址后按 `Ctrl+C`    | 粘贴为空 |
| 在地址栏全选网址后右键复制       | 粘贴为空 |

“部分选中能复制、全选复制为空”是最有用的差异。排查范围因此缩小到了地址栏复制完整网址时的处理过程。

## 排查与原因

### 检查复制前后的剪贴板内容

最初检查系统剪贴板，可以正常写入和读取文字。结合网页正文复制正常的现象，暂时没有证据表明系统的全部复制功能失效。

随后先在剪贴板里放入一段用于对照的文字，再执行地址栏全选复制。排查记录显示，原有文字被清空；进一步检查时，剪贴板仍有文本格式，但读到的内容是空字符串。

这说明执行复制后，剪贴板的文本内容发生了变化。仅凭这个结果，还无法确定是 Edge 生成了空文本，还是复制过程中有其他程序干预。

### 无痕窗口和英文输入布局都没有改善

在 InPrivate 无痕窗口中重复操作，仍然粘贴为空；切换到英文输入布局后，问题也依旧存在。这两次尝试都没有绕过故障。

排查时还问到了 Snipaste、ShareX 一类截图或剪贴板工具，但记录没有逐项退出这些工具的对照测试。无痕窗口中的扩展启用情况也没有完整记录，因此不能把扩展和常驻工具的影响完全排除。

### 为什么检查 URL 复制格式

微软的官方说明确认，Edge 对地址栏网址提供专门的复制和粘贴格式功能：可以粘贴网址，也可以粘贴带网页标题的超链接。因此，完整网址的复制结果还会受到这项功能的影响。

结合只有完整网址复制异常的现象，排查转向了 URL 复制格式设置，并最终通过开启图中的开关恢复。现有证据支持把故障定位到与地址栏 URL 复制格式有关的行为；“富文本生成过程中的纯文本部分出错”仍是推测，没有内部调用记录或浏览器源码调试证据支撑。

## 验证结果

本次开启开关后，地址栏全选复制恢复正常。原始记录没有保存 Edge 的具体版本号，也没有跨设备、跨版本测试，不能据此认定所有地址栏复制失败都由同一原因造成。

调整后可以回到网页，按 `Ctrl+L` 选中完整地址，再按 `Ctrl+C`，到记事本中粘贴；随后再用右键复制重复一次。两种方式都能粘贴出非空的网址，才说明这台设备上的原症状已消失。
