CC Switch now supports locally proxying ChatGPT models so that they can be used in Claude Code.

# Prerequisites

1. Prepare CC Switch: [download it here](https://github.com/farion1231/cc-switch/releases/download/v3.11.1/CC-Switch-v3.11.1-Windows.msi).
2. Install Claude Code.
3. Have a ChatGPT provider key and URL ready.

# Steps

1. Open CC Switch and create a Claude Code configuration like the one below. Enter the ChatGPT provider URL and key, then select `responses` as the API format.

![Configuration example](/images/notion/claude-code-chatgpt-34a4342e/image-1.png)

2. Open the Settings button in the upper-left corner of CC Switch. Enable the proxy and enable Claude Code.

![CC Switch settings](/images/notion/claude-code-chatgpt-34a4342e/image-2.png)

3. Open Claude Code and start using it.
