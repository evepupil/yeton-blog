Apple released macOS 27 (Golden Gate) on September 14, 2026, and it runs only on Apple silicon Macs, so the newest macOS a regular Intel or AMD PC can run is macOS 26 Tahoe, currently at 26.7. Tahoe removes the onboard audio driver and leaves Broadcom Wi-Fi with only an experimental driver, so macOS 15 Sequoia is the safer install. The least troublesome parts are a 10th-gen Intel CPU, an AMD RX 6600 and a Broadcom BCM94360CD Wi-Fi card; the lists below reflect the official docs, driver notes and public configs available on September 24, 2026.

## macOS 26 Tahoe Is the Ceiling

On Apple's security releases page, every Mac listed for macOS Golden Gate 27 has Apple silicon. In June 2026 the OpenCore Legacy Patcher (OCLP) team, which patches newer macOS onto unsupported Macs, explained that the first macOS 27 beta had already removed most kernel extensions for Intel hardware, that what remains is not enough to boot the release, and that there are no plans to attempt it.

Tahoe officially supports four Intel Macs: MacBook Pro (16-inch, 2019), MacBook Pro (13-inch, 2020, Four Thunderbolt 3 ports), iMac (27-inch, 2020) and Mac Pro (2019). A Hackintosh boots through the OpenCore bootloader and presents itself as a specific Mac model, an identity called the SMBIOS. Dortania, which maintains the OpenCore Install Guide, lists only these four identities in its Tahoe notes; desktops typically use iMac20,1 (10th-gen Intel with the iGPU) or MacPro7,1 (an AMD card drives every display).

Dortania's Tahoe notes list four things that need handling beyond Sequoia:

- Apple removed the AppleHDA audio driver, so onboard headphone jacks and speaker outputs go silent.
- Broadcom Wi-Fi works only through the experimental AppleBCMWLANCompanion driver.
- Intel Bluetooth needs the `-ibtcompatbeta` boot argument.
- WhateverGreen, the usual AMD GPU helper, has connector-patching problems; for now the only fix is to remove it.

Official OCLP support still stops at Sequoia. TidBITS estimated that, if Apple keeps its current policy, Tahoe gets two more years of security updates and Intel Macs lose security viability in 2028; by the same policy, Sequoia's updates end about a year earlier. Install Sequoia if you want onboard audio and Broadcom Wi-Fi without fuss; install Tahoe if the extra year of updates is worth working around the headphone jack and running experimental Wi-Fi.

| Intel 4th gen (Haswell)                                          | With tweaks     | No iGPU driver since macOS 13, so a discrete card is needed; one iGPU-only machine boots Tahoe 26.3.2 without graphics acceleration             |
| Intel 6th/7th gen                                                | Unknown         | No public config found running Tahoe                                                                                                            |
| AMD Ryzen 1000–7000, Threadripper                                | With tweaks     | Relies on the AMD_Vanilla kernel patches, which list Tahoe as supported; Ryzen 7000 also needs an IOPCIFamily patch                             |
| AMD Ryzen 9000                                                   | Few examples    | The patch notes don't mention this generation; one Ryzen 5 9600X build runs Sequoia                                                             |

Among the AMD limitations in Dortania's Anti-Hackintosh Buyers Guide, these affect daily use:

- Sleep is hard to set up and impossible on some systems; there is no CPU power management.
- Virtual machines built on Apple's hypervisor framework (such as Parallels) and Docker don't work.
- Some Adobe apps misbehave and Lightroom has no fix; audio apps such as Cubase and REAPER crash on launch.
- Onboard microphone input doesn't work, and some boards have USB ports that stay dead.

## Motherboards

On Intel boards, first check whether the BIOS can disable CFG Lock (write protection on a CPU power-management register). Dortania states that a machine will not boot with CFG Lock enabled; if the BIOS has no such option, enable `AppleXcpmCfgLock` in the OpenCore config to work around it. heipg.cn, a Chinese Hackintosh community site, recommends boards whose BIOS exposes the option and notes many successful installs on Gigabyte Vision D/G and MSI MORTAR boards.

On enthusiast and server platforms such as X79, X99, X299, C612, C621 and C422, some boards have no working NVRAM (the firmware storage that keeps boot settings); ASUS X299 boards are the exception.

## Graphics Cards

Discrete cards have to be AMD. Dortania's GPU Buyers Guide is only verified up to Sequoia 15. For Tahoe, look at the Mac Pro (2019), which Tahoe still supports: its options include the Radeon Pro 580X, W5500X, W5700X, Vega II, W6600X, W6800X and W6900X, covering the RX 500, RX 5000, Radeon VII and RX 6600/6800/6900 architectures. Apple has to ship drivers for that machine, so these architectures still work on Tahoe.

| GPU                                         | Verdict     | Notes                                                                                                                                                              |
| ------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| RX 6600, RX 6600 XT                         | Best pick   | Native, Metal 3, used in public Tahoe configs                                                                                                                      |
| RX 6800, RX 6800 XT, RX 6900 XT             | Works       | Native, Metal 3; one Tahoe config notes the RX 6900 XT runs without WhateverGreen                                                                                  |
| RX 5500 XT, RX 5600 XT, RX 5700, RX 5700 XT | Works       | Native, Metal 3                                                                                                                                                    |
| RX Vega 56/64, Radeon VII                   | Works       | Native, Metal 3                                                                                                                                                    |
| RX 460 to RX 590                            | Works       | Native and the cheapest; no Metal 3 (Apple's current graphics API)                                                                                                 |
| RX 6650 XT, RX 6950 XT                      | With tweaks | Spoof the device ID as RX 6600 XT or RX 6900 XT                                                                                                                    |
| RX 580 2048SP                               | With tweaks | A cut-down variant common in China; flash an RX 570 VBIOS to run natively                                                                                          |
| RX 6700, RX 6700 XT, RX 6750 XT             | With tweaks | No Apple driver; needs the third-party NootRX kext, which Dortania calls a work in progress that is not fully functional                                           |
| RX 6400, RX 6500 XT                         | No          | NootRX doesn't support this generation yet                                                                                                                         |
| RX 7000 and RX 9000 series                  | No          | No driver; Dortania considers RX 7000 support unlikely ever                                                                                                        |
| All NVIDIA                                  | No          | Kepler (e.g. GTX 660–780, some GT 710/730) tops out at Big Sur 11; GTX 745/750, GTX 900 and GTX 10 series top out at High Sierra 10.13; newer cards have no driver |
| Intel Arc                                   | No          | No driver                                                                                                                                                          |

Most RX 5000 and RX 6000 cards need the `agdpmod=pikera` boot argument to get a display out.

Intel iGPU support ends at 10th gen (UHD 630, UHD 620 and similar) and the Iris Plus in Ice Lake laptops; 11th-gen and later iGPUs, Iris Xe and Core Ultra graphics have no driver. One build forced Tahoe onto Iris Xe and got no graphics acceleration, with the CPU drawing every window. UHD 630 runs Metal 3 on Tahoe, but the HP ProDesk 400 G7 author saw the UI freeze and the machine black-screen and reboot under long heavy loads, and finally added an AMD card.

The Vega iGPUs in Ryzen 1000 to 5000 and 7x30 APUs rely on the third-party NootedRed kext, which states compatibility up to macOS 26; a ThinkPad T495 Tahoe config uses it for graphics acceleration.

For DRM-protected video such as Apple TV+ and Netflix, WhateverGreen's documentation says that since macOS 11 only Mac models without an iGPU, paired with a compatible AMD card, get full playback; iGPU-only machines can't play it.

## SSDs

Dortania recommends drives with Western Digital's own controllers, such as the WD SN750, or Phison-based drives such as the Sabrent Rocket; the Samsung 970 EVO Plus needs a firmware update first. Avoid these:

- Samsung PM981 and PM991: common as laptop OEM drives and prone to kernel panics. The ThinkPad T490 config says the stock PM981a must be replaced as well.
- Micron 2200S: users report it won't boot.
- SK Hynix PC711: its controller isn't supported at all.
- Intel 600p: known issues; the 660p is fine.

Samsung drives in general tend to stutter and have TRIM problems. Add the NVMeFix kext for any NVMe drive; it supports up to macOS 26, though some fixes, such as the timeout panic fix, may not apply on newer versions.

## Audio

Up to Sequoia, onboard Realtek ALC codecs work through AppleALC in most cases. Tahoe dropped AppleHDA starting with developer preview 2, which leaves AppleALC with nothing to drive, so headphone jacks and speaker outputs go silent; HDMI and DisplayPort audio and USB audio devices are unaffected, and the Lenovo M70q Tahoe config states that only HDMI audio works.

To use the headphone jack on Tahoe:

- Buy a class-compliant USB audio interface or DAC; this is the simplest option.
- Switch to the VoodooHDA driver, which may sound worse.
- Relax SIP and put the old AppleHDA back onto the system volume.

## Suggested Builds

- **Least hassle**: a 10th-gen Intel CPU (i5-10400 or i7-10700), a Z490 or B460 board whose BIOS can disable CFG Lock, an AMD RX 6600, a Broadcom BCM94360CD Wi-Fi card and a WD SSD, running Sequoia.
- **Newer platform**: 12th–14th-gen Intel on a Z690 or Z790 board with an RX 6600 or RX 6800-series card; accept the CPU spoof, P/E-core handling and an unusable iGPU.
- **AMD**: Ryzen 3000 or 5000 on a B550 or X570 board, once you have accepted the sleep, virtualization and pro-app issues.

Two features stay out of reach whatever you buy: iPhone Mirroring requires Apple's T2 security chip, and fingerprint readers have no driver. PCs will get no macOS release after Tahoe, so before buying new parts for a Hackintosh, count on security updates ending around 2028.
